<ktjs-features section-title="为什么用 Kotlin 写前端动画" tinted>

<ktjs-feature icon="lucide:type" title="带类型的参数">`animationParams`、`timelineParams`、`timerParams`、`staggerParams` 都是接口：写一个不存在的选项就是编译错误。</ktjs-feature>

<ktjs-feature icon="lucide:layers" title="动画核心完整封装">`animate`、`createTimeline`、`createTimer`、`stagger`、`Timer`/`JSAnimation`/`Timeline` 层次、`anime.utils` 与 `anime.easings`。</ktjs-feature>

<ktjs-feature icon="lucide:clock" title="可选参数真的是可选的">anime.js 默认把参数解构为 `{}`，所以 wrapper 提供真正的零参数重载，而不是转发 `null`。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="在 Chromium 里测试">模块的测试对真实元素创建真实动画，演示页另有 Playwright 套件，连语言切换一起验证。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">每个页面都有英文与简体中文两版，结构一致，并各自跳转到演示页与 Dokka API 文档。</ktjs-feature>

</ktjs-features>
