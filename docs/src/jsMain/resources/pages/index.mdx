<ktjs-features section-title="Why write animations in Kotlin" tinted>

<ktjs-feature icon="lucide:type" title="Typed parameters">`animationParams`, `timelineParams`, `timerParams` and `staggerParams` are interfaces, so an option that does not exist is a compile error.</ktjs-feature>

<ktjs-feature icon="lucide:layers" title="Animation core, fully wrapped">`animate`, `createTimeline`, `createTimer`, `stagger`, the `Timer`/`JSAnimation`/`Timeline` hierarchy, `anime.utils` and `anime.easings`.</ktjs-feature>

<ktjs-feature icon="lucide:clock" title="Optional arguments stay optional">anime.js destructures `{}` by default, so the wrapper offers real zero-argument overloads instead of forwarding `null`.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in Chromium">The module's tests create real animations against real elements, and the demo has its own Playwright suite that also checks the language switch.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">Every page exists in English and Simplified Chinese, with the same structure, and links out to the demo and the Dokka reference.</ktjs-feature>

</ktjs-features>
